# How to install the pack:

Simply download the content as a .zip file, then—after making your modifications (note that this pack does not include a panorama; you will need to create one yourself)—rename the .zip folder to .mcpack. Double-click it, and your pack will be imported into Minecraft Bedrock.

# Specifications: 

You'll notice that this pack won't import if you've already imported it into your game. To change this, you'll need to go to a UUID v4 generation website. Here's a link: Generate your UUID, then replace the UUID on line 6 in the manifest.json file. Next, generate another UUID and do the same with line 14. Recompress the files into a .zip file, then rename it to .mcpack (also rename the .mcpack file so you can easily identify it).
